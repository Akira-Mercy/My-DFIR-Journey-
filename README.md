PC System Fundamentals, Disk Sectors and Partition Analysis
Overview
This repository contains my practical lab assignment on PC System Fundamentals, completed as part of my ICDFA Digital Forensics and Incident Response (DFIR) training.
Topics Covered
Hard disk components and geometry.
Disk sectors, tracks, cylinders and heads.
Disk partitioning and partition tables.
File systems and their importance in digital forensics.
BIOS, UEFI and the boot process.
MBR and GPT partitioning schemes.
Partition size calculation and verification.
Skills Acquired
Identifying disk and partition information.
Understanding disk structure and storage organisation.
Calculating partition sizes using sector information.
Understanding how file systems organise and store data.
Recognising the importance of disk structures in digital forensic investigations.
Purpose
To develop foundational knowledge of computer storage systems and understand how disk structures, partitions and file systems contribute to digital forensic examinations.
